# TsFlowy

本地优先的 Windows 桌面笔记与知识管理应用：文档编辑 + 数据库（表格 / 看板 / 日历 / 时间线 / 列表 / 画廊 / 表单）+ 全局搜索，数据全部保存在本机，无需账号、不依赖云服务。

基于 **Tauri 2（Rust）+ React 19 + TypeScript + TipTap + SQLite** 构建，安装包约 7 MB。想直接使用可从 [Releases](https://github.com/rayfengleixing/tsflowy/releases) 下载最新安装包；从源码构建与使用见下文。

## 功能特性

### 文档编辑

- 所见即所得富文本编辑器（TipTap / ProseMirror）：标题、段落、项目符号 / 编号 / 任务清单、引用、分割线、提示块（callout）、折叠块（toggle）、表格
- 表格：右键单元格增删行列、删除整表；在单元格上按住 `Shift` 拖动可框选一片，右键即可合并 / 拆分单元格。Markdown 导出会把合并摊平成矩形网格（GFM 没有跨行跨列语法），HTML 导出保留 colspan / rowspan
- 分栏：`/` 斜杠菜单插入两栏，悬停工具栏可切 2 / 3 / 4 列或一键均分；拖动相邻两栏之间的分隔条调整栏宽（比例随文档保存，Markdown / HTML 导出都带得走）
- 提示块配色与段落对齐：callout 有 6 种底色与 emoji，块级对齐（左 / 居中 / 右）在块菜单里设置。Markdown 没有这两种语法，导出时在首行或行尾追加 `<!-- color:green -->`、`<!-- align:center -->` 注释，导入时摘掉；默认蓝与左对齐一律不写标记，旧导出文件读回来格式不变。`justify` 读得回来，只是块菜单暂未提供这一档。HTML 导出把颜色落成 `callout-<色名>` class、对齐落成 `text-align`
- 任务清单的截止日期与负责人：点任务列表的块手柄打开面板，用「上一行 / 下一行」在行之间移动，可设日期（含「今天」快捷键）、清除、填负责人。行尾会出现 📅 / 👤 chip，逾期与当天另有配色。Markdown 用行尾 `<!-- task due=2026-10-20 assignee=张三 -->` 承载这两个字段（GFM 无此语法），无元数据的行不写标记；HTML 导出把 chip 落成 `.task-meta`，状态 class 为 `.task-meta-today` / `.task-meta-overdue`。负责人上限 40 字并会去掉 `<` `>`（否则撑破行尾标记）
- 代码块带语法高亮；数学公式（KaTeX）
- 文字颜色 / 高亮底色 / 图片说明的 Markdown 往返：Markdown 没有这三样语法，导出时分别写成 `<span style="color: #0092D6">…</span>`、`<mark data-color="#FEF3C7" …>…</mark>` 和标题位 `![alt](src "说明")`，导入原样读回；两段 HTML 就是编辑器自己的渲染形式，粘到别处也认。默认高亮仍走 `==文本==`、无说明的图片不写标题位，旧导出文件读回来格式不变。说明文字里的半角括号会截断图片语法，导出时折成全角、引号折成单引号
- 输入 `/` 呼出斜杠菜单快速插入内容块；选中文本弹出浮动工具栏（加粗 / 斜体 / 下划线 / 删除线 / 高亮 / 文字颜色 / 链接）
- 页内查找替换（`Ctrl+F`）：区分大小写、全词匹配、正则表达式三个开关可组合，命中用 `Enter` / `Shift+Enter` 逐个跳转；正则档的替换串按 JS 语义展开捕获组（`$1`、`$&`、`$$`），表达式写错时底部直接说明而不是报「无结果」。命中上限 1000 处，超出部分不高亮、全部替换也只作用于这 1000 处（底部会提示）
- 三种编辑器模式（设置 → 编辑器模式，命令面板可直接切换，绑键在设置 → 快捷键改）：**只读**锁住正文——输入、粘贴、块拖拽、查找替换里的替换全部失效，阅读 / 选中 / 复制不受影响，编辑区右下角出现「只读」标记（默认 `Ctrl+Alt+R`，跨启动保留）；**专注**收起侧边栏、标签页、AI 面板与反链，只留正文，右上角按钮或 `Esc` 退出（默认 `Ctrl+Alt+F`，只在工作区生效，不跨启动保留）；**打字机**把光标行钉在编辑区中线，新内容往下长而不是攒到屏幕底部再翻页（默认 `Ctrl+Alt+M`，跨启动保留）
- 块级拖拽手柄：拖动任意内容块调整顺序；Shift 点击手柄可连续多选整段搬移 / 删除（可撤销），`Alt+↑/↓` 移动当前块或整段。点手柄弹出的块菜单里「复制 / 剪切」会同时写入 HTML 与纯文本两份，粘回编辑器或别的富文本工具能保住列表 / 表格 / 标题 / 图片这些结构（图片块的纯文本本来是空的，全靠 HTML 那份）
- 图片：上传 / 粘贴 / 拖拽插入，可添加说明文字（caption），双击打开灯箱放大；支持图片组（多图网格展示）
- 附件：卡片式展示，点击文件名那行用系统默认程序打开；图片 / 音频 / 视频 / PDF 另有一块内嵌预览（音视频与图片默认展开，PDF 较重，点右侧箭头展开）。类型只看扩展名判定，Chromium 播不了的容器（avi / mkv / zip 等）仍只是卡片。HTML 导出会把可预览的附件内嵌成 `<img>` / `<audio>` / `<video>` / `<iframe>`，配合随导出落盘的 `assets\` 目录离线也能看；Markdown 仍是 `[名称](attach:…)` 链接
- 右下角常驻字数统计：中文按字、英文按词，中英混排两边都算（汉字充当词边界），并给出预计阅读时长（中文 300 字/分、英文 220 词/分别折算再相加）；选中一段时额外显示选中字数
- `@` 提及：链接到其他页面，悬停预览内容，点击跳转；页面底部显示反向链接（backlinks）
- 子页面、内嵌数据库视图（在文档中嵌入数据库表格预览，或插入跳转链接卡片）
- 大纲面板：实时收集 H1–H6，滚动时高亮当前章节，点击跳转
- 首行一级标题即页面标题：编辑区内修改会同步页面名，侧边栏重命名也会写回标题

### 数据库

- 多视图：同一张数据表可拥有多个视图（表格 / 看板 / 日历 / 时间线 / 列表 / 画廊 / 表单），每个视图独立保存筛选、排序、分组等显示配置，顶部标签栏随时切换
- 列表视图：一行一条记录，主字段当标题、其余可见字段横向排在右边（空字段不占位），点整行打开行详情——列宽受限的表格视图读长内容时换成它
- 画廊视图：卡片墙，封面取自附件字段里的第一张图片（在顶栏切换用哪个附件字段），副信息与看板卡片共用「卡片字段」配置；没有附件字段时给出回表格视图的引导
- 表单视图：一条记录占一屏、字段自上而下逐格录入，用顶栏「上一行 / 下一行」按当前筛选与排序连续录入——多行文本、附件、关联这类在窄列里挤着改的字段，在这里有整行宽度
- 字段类型：文本、数字、日期、状态、单选、多选、复选框、URL、电话、邮箱、关系、反向关系、汇总、公式、附件，以及自动维护的创建时间 / 最后编辑时间
- URL / 邮箱列可点：单元格里点文字就用系统默认程序打开（链接走默认浏览器，邮箱写 `mailto:` 交给默认邮件程序），与附件胶囊同一套手感——点文字是打开，点格子的其它位置照常进编辑。没写协议的链接按 `https://` 补全；`javascript:`、`file:` 之类不认作链接，仍旧当纯文本显示，不会被递给系统。电话列不做成可点：Windows 上没有可靠的 `tel:` 处理程序
- 状态字段：单选的一种，选项带「未开始 / 进行中 / 已完成」阶段——阶段决定新建选项时的默认配色，「已完成」的选项在表格胶囊与看板列头上打勾；看板可直接按状态字段分列并按阶段排序
- 关系字段可关联到另一张数据表；反向关系字段按「来源表 + 来源表的关联字段」列出关联到当前行的所有行（只读虚拟列）；汇总字段按聚合函数（求和 / 计数 / 平均等）聚合关联行的值；公式字段引用本行其它字段计算
- 关联胶囊可点：表格与行详情里点关系 / 反向关系列上的胶囊直接跳到对端那一行（复用深链的定位路径：目标页未加载时排队等树，到位后滚动并短暂高亮）。对端行已删除或目标库还没加载时胶囊退回纯文本，点了不会跳去一页空白
- 附件字段可在单元格挂多个附件（文件对话框选择或拖拽上传，复制进数据目录 `assets/`），表格与行详情中可添加、打开、删除；图片附件直接显示缩略图
- 表格视图：按字段分组并显示分组小计、底部合计行（每列可选汇总函数：计数 / 已填写 / 唯一值 / 求和 / 平均 / 中位数 / 最小值 / 最大值 / 勾选数 / 占比）、列统计、筛选与排序
- 多级分组：表格视图最多叠三层分组（第一层选字段，后面用「再按…」逐层追加），每层各自折叠、各自出小计，父层小计覆盖它整棵子树的行
- 嵌套筛选：条件可以装进「条件组」——组内用组自己的且 / 或，组之间再用顶层的且 / 或，最多嵌三层；不想要的组或条件直接删掉，空组不会误把整张表筛空
- 列汇总的中位数与占比：中位数按该列已填写的数字取中（偶数个取中间两数的均值，空格不参与）；占比拿「当前筛选后的整张表」当分母——数字列比求和，其余列比已填写行数，所以分组时每组的小计占比能直接看出这组占全表多少，底部合计行作为全集恒为 100%
- 条件格式：给满足条件的单元格或整行上色（7 档颜色，规则最多 20 条）——比较符与筛选完全同一套（包含 / 等于 / 大于 / 为空 / 已勾选…），操作数控件也共用，所以「数字列比大小、单选列点选项」这些手感不用重新学；条件只看当前行的值，公式 / 汇总列同样能当判定列
- 看板视图：按单选字段分列，卡片展示字段可配置
- 日历视图：按日期字段铺排
- 时间线视图：按日期字段把行横排到时间轴上，可选「开始 / 结束日期字段」画成横跨条，刻度支持自动 / 日 / 周 / 月
- 行详情面板：逐行查看与编辑完整字段
- 批量改值：在表格视图勾选多行后一次改掉同一个字段——文本 / 数字 / 日期 / 状态 / 单选 / 多选 / 复选框都支持，多选另有「追加 / 移除」两档、复选框可「取反」；本来就是目标值的行自动跳过
- 写入前的类型把关：单元格落库前会按字段类型核一遍值的形态（编辑器、粘贴解析、AI 归一本来就各管各的，这一层兜住绕过它们的路径，比如老数据里形态已经错的格子被原样回写）。单格不合规则取消这一格并提示是哪个字段；批量写入（粘贴、批量改值）只剔除不符的那几格，其余照常落库并提示跳过了几格。清空任何类型都合法，公式 / 汇总 / 反向关系与触发器维护的时间列的值由计算与触发器生成，不参与这套判定
- CSV 导入 / 导出；导入时可把某列指定为「附件」类型并按文件名匹配本地文件夹中的文件
- xlsx 导出：表格视图把当前页（筛选 / 分组后的行序、隐藏列除外）另存为 Excel 工作簿。数字 / 进度 / 评分 / 货币列写成真数值，勾选写成布尔，日期列写成 Excel 日期（字段开了「含时刻」就是日期时间），关联与反向关系折成对端行标题（`; ` 分隔，与 CSV 同一份取值规则），公式 / 汇总取页面里算好的展示值。写入由 Rust 侧手写 OOXML 完成，不引入新的依赖
- 父子行层级：行名末尾悬停出现的「⋯」菜单里可「新建子行」「设为其他行的子行」「升为顶层行」；拖拽行时长按 Alt 落到另一行上即把它嵌套进去（能接住的行会高亮，否则只是普通改顺序）；子行紧跟在父行下方并按层缩进，父行左侧的三角折叠它整棵子树，最多 4 层，选父行的列表已经排除自己、自己的后代与会让子树超深的行；行详情面板顶部同样有「父行」一行，可以在那里换父级或就地补子行

### 组织与检索

- 工作区（空间）切换、侧边栏页面树（拖拽排序、右键菜单、新建页面 / 数据库）
- 页面树：单击即打开页面，右键整行（或行尾 `⋯`）弹出行菜单，菜单里的「选择 / 取消选择」把这一页加进或移出多选选区；`Ctrl` 点选加撤单页、`Shift` 点选连一段、`Ctrl+A` 全选当前可见页。多选之后在选中的任意一行上右键，菜单的收藏 / 删除那几项就变成「收藏 N 项 / 取消收藏 N 项 / 删除 N 项」，一次作用在整组（删除走回收站，父子同选只算父页一次，子页跟着整棵走）；只右键选区外的一行时先落回单页，菜单仍是这一页的收藏 / 删除。拖动选区里的任意一行 = 整组一起搬；按下后手指抖了几个像素不会被当成拖拽。键盘：`Tab` 落到焦点行，`↑/↓/Home/End` 移焦点、`Shift+↑/↓` 扩选、`←/→` 收起 / 展开（收起时 `←` 回父页）、`Enter/空格` 打开、`Delete` 批量删除、`Esc` 取消选择
- 多标签页 + 面包屑导航：标签栏可用键盘操作——`Tab` 落到当前标签，`←/→` 在标签间移焦点（不切页）、`Home/End` 到首末，`Enter/空格` 打开；`Ctrl+Tab` 直接切页、`Ctrl+W` 关闭当前页，标签上的关闭按钮在键盘聚焦时也会显形（平常只在悬停时出现）
- 回收站：软删除、恢复、彻底删除，删除满 30 天自动清理
- 标签：给页面打标签，侧边栏「标签」页按标签聚合浏览
- 每日笔记：一键打开当天笔记（可改日期、前后翻页），自动收纳在固定目录页下；正文模板可在设置中自定义（支持 `#` 小标题、`- [ ]` 待办、`{{date}}` 占位符），也可设为启动时自动打开
- 全局搜索（`Ctrl+Shift+F`）：覆盖页面标题、正文与数据库单元格，命中行可一键定位
- 命令面板（`Ctrl+K`）：快捷动作 + 输入即搜页面；输入还能当参数用——`新建页面「你输入的字」`、`切换到空间「…」`（只有名字对得上现有空间时才出现），排在搜索结果之后，不抢跳转
- 深链跳转：`tsflowy://page/<页面 id>` 从浏览器或其它程序拉起本应用并打开该页；数据库行详情的「复制行链接」给出 `tsflowy://page/<页面 id>?row=<行 id>`，打开后滚到那一行并短时高亮（与搜索命中定位同一套）

### AI 助手

- 可折叠的侧边 AI 面板：多轮对话、流式输出、思考过程展示，支持停止 / 重试 / 清空 / 复制
- 快捷动作：总结当前页、翻译选中、改写选中、解释选中
- 答案排版：代码块语法高亮、`mermaid` 围栏画成图、`$…$` / `$$…$$` 公式按 KaTeX 渲染
- `@` 引用文档：输入框敲 `@` 弹出当前工作区文档列表，可一次引用多篇，发送时转为 Markdown 作为参考文档
- 上下文范围三档（面板顶部下拉，或设置 → AI 助手，改完下一轮问答即生效，随配置入备份）：**全部** = 当前页正文 + `@` 引用 + 检索工具（默认）；**仅本页** = 只带当前文档，检索与其它文档都不下发（模型照旧发检索请求时不会执行，会把原因回灌再要一轮答案，正文末尾说明一句）；**关闭上下文** = 当前文档一个字都不带（你在编辑器里选中的文字、`@` 主动引用的文档仍会带上，那是你给的）。整页正文最费 token，也最可能把没打算给模型看的段落带出去，不确定就切到「仅本页」
- 答案里的引用可点：模型引用的页面（检索结果里的 `[id=…]` 标记）渲染成小胶囊，点了直接打开那一页——与深链同一条排队路径，页面此刻没加载好会等它出现再跳；解析不到的 id 原样留作文本，不会变成点不动的假链接。代码块里的同样子串不受影响
- 结果落地：一键插入到光标处或替换选中内容；模型也可通过指令块直接修改文档，并提供「撤销本次修改」
- 服务商可配置：内置 DeepSeek、通义等预设，也支持 OpenAI 兼容的自定义接口；API Key 存入系统凭据管理器（Windows Credential Manager），不落明文

### 导出、导入与备份

- 当前页面导出：Markdown / 长图 PNG / PDF
- 整个工作区备份导出与导入（打包数据库与附件资源，可整体迁移）
- 整库导出为 Markdown 文件夹：按目录结构导出全部文档页面，便于迁移到其它工具
- 页面历史版本：编辑过程中自动保存快照（每页保留最近 50 份），可逐版本对比改动（这一版相比上一版、或相比当前内容，按 Markdown 逐行增删），也可一键恢复；恢复前会先自动备份当前内容
- 自动备份：按间隔把数据库与附件打包到数据目录下的 `backups` 文件夹，只保留最近若干份
- 导入 Markdown 文件夹：按目录结构批量建页

### 多机同步

- 双向同步（同步文件夹方案）：指定一个文件夹（OneDrive / 坚果云 / Dropbox 的同步目录，或已挂载的网盘盘符），点「立即同步」按时间戳双向对齐数据库与附件
- 两端都改过时以较新的一份为准，被舍弃的一份保留为冲突副本（保留最近 5 份），不会静默丢数据

### 外观与设置

- 浅色 / 深色 / 跟随系统主题；强调色与正文字体可选；界面支持中文 / English，切换语言时系统托盘菜单跟着换（托盘是系统控件、网页渲染不到，文案在 Rust 侧另存一份，由前端把当前语言报过去重建；认不出的语言退回中文）
- 窗口不带原生菜单栏（文件 / 编辑 / 视图 / 窗口那一排）：新建 `Ctrl+N`、设置 `Ctrl+,`、命令面板 `Ctrl+K`、撤销与剪贴板照常在编辑器里，最小化 / 关闭看标题栏，退出走窗口 X 或托盘右键
- 数据目录可迁移（设置内指定自定义位置），备份一键导出
- 软件更新：默认只在设置页点「检查更新」时联网；可勾「启动与每日自动检查」，启动约 20 秒后与每天一次静默问一遍更新源，发现新版本只弹一条提示（点提示直达设置页，下载与安装仍要手动确认），同一个版本不重复唠叨，离线/更新源不可达时静默记日志不打扰
- 开机与崩溃（设置 → 开机与崩溃）：「登录时自动启动」写当前用户的注册表登录启动项，不需要管理员权限，面板会回显实际登记的启动命令，装在第二个位置时先关再开一次开关即可改到当前这份；「崩溃后自动重启」在程序内部出错退出时自动再拉起一次（连续崩溃最多两轮，之后停下等手动打开），重启起来后弹一条带轮次的提示，原因看日志文件。第三方组件内部的崩溃抓不到，不属于这一条
- 读屏器可达性：图标按钮、色块、拖拽手柄（侧边栏宽 / 分栏线 / 列宽 / AI 面板宽）与只有占位符的输入框都带可访问名；选区气泡菜单与块菜单标成工具栏，反链条目、筛选/排序条、看板与日历的折叠按钮不再是「无名按键」；正文区与标签页按 `tab` ↔ `tabpanel` 配对（专注模式没有标签栏时退回 `main` 地标，并排右栏单独是「右侧正文」区域），AI 面板是命名 complementary 区
- 内置快捷键速查表（全局与编辑器两组）
- 数据库健康诊断：启动时若数据库无法打开，给出诊断信息与重建入口

## 已知限制

- **AI API Key**：保存在本机 Windows 凭据管理器（服务名 `TsFlowy`，全局 Key 为账户 `ai-api-key`，各模型档位各一条 `ai-api-key:profile:<档位 id>`）；若凭据管理器不可用则回退到 `config.json`（位于用户专属的 `%APPDATA%` 目录，ACL 已限本用户），界面会明示
- **同步与备份均为明文**：同步文件夹里放的是 `data.db` 与 `assets/` 两份明文（任何 SQLite 工具都能打开库、任何图片查看器都能打开附件），应用层不做端到端加密——传输加密、账户隔离与静态存储保护全部依赖所选网盘自身；OneDrive / 坚果云 / Dropbox 这类服务商在服务器上看到的就是你的原文。要换掉这层信任只有一条路：把同步目录指到本机可控、且自身已加密的位置（BitLocker 加密盘、需要客户端侧加密的网盘、内网 NAS）。同步范围也只有这两样——`config.json`（含偏好与自动备份设置）不走同步，只进备份包；zip 本身不加密，若凭据管理器不可用、API Key 回落到 `config.json`，备份包就会带上明文 Key，这种备份别放到他人可读的位置
- **时间线视图**：为只读 v1，暂不支持在时间轴上拖拽改期；结束时长为 0 的行按「点」绘制
- **表单视图**：一次录入一条记录，字段必填校验、对外分享表单链接还没有；显示字段跟随表格视图的隐藏列设置
- **列表 / 画廊视图**：两者都只读（改值走行详情或表格视图）；显示的字段跟着表格视图的隐藏列走，画廊封面只认扩展名判定为图片的附件
- **批量改值**：附件与关联字段不参与（前者要文件对话框、后者要行选择器，「N 行填同一个值」的语义都不成立）；入口在表格视图的勾选行操作条上
- **状态字段**：阶段（未开始 / 进行中 / 已完成）挂在选项上，需在字段设置里逐个选；CSV 导入或 AI 新建的状态选项一律按「未开始」起步，旧库里的单选字段不会自动变成状态字段（值形态相同，改名改类型仍要手动）
- **筛选与分组**：嵌套条件组与分组层级都最多三层；求值全在前端完成（没有 SQL 下推），大表仍是整表载入后再筛选、再摊平
- **条件格式**：只在表格视图生效（看板 / 日历 / 卡片不铺色）；条件只能看当前行自己的单元格，写不出「高于本列平均值」「与上一行不同」这类跨行判定——那要先给每列做一次统计再回填，与「每格 O(1) 查色」的实现相冲，且筛选一变含义就跟着变。同列上单元格规则优先于整行规则，同一档内按规则顺序先到先得
- **汇总字段（rollup）**：聚合函数可选到平均 / 中位数 / 最小最大，但没有「占比」——占比的分母得是整张表，而 rollup 的统计范围只有本行关联到的那几行，算出来恒等 100%，不如不给
- **xlsx 导出**：单表单个工作表，只带列宽、表头冻结与日期格式，其余样式（配色、粗体、数字格式）不落盘；百分比 / 货币列导出成原始数值，与 CSV 一样要在 Excel 里自行套格式；解析不了的日期回落成文本，同一列里会数值与字符串混排。导入仍只有 CSV
- **行级深链**：链接只带页面 id 与行 id，落点仍是打开页面时停留的那个视图——视图切换、以及行被当前筛选排除时不会自动切过去或放开筛选，那种情况链接只打开页面、看不到高亮（行已删除同理，静默忽略）。深链是本机协议、没有权限模型，拿到链接的人都能跳到那条记录
- **父子行层级**：层级只决定表格视图（未分组时）的显示顺序，父行本身不是单元格值，因此筛选 / 排序 / 分组 / 汇总 / 看板都认不出它，分组一旦生效就按组的顺序铺行、不再按树展开；其余视图与 CSV / xlsx 导出都是平铺的行。折叠状态留在本机，换视图或重开页面回到全展开。被筛掉的父行不会带走子行——父行不在当前行集里时子行抬到顶层显示。复制行（多选后的「复制所选」）会跟着保留层级：一起被复制的父行会被子行认到副本上，只复制子行时它仍挂在原来的父行下（父行已不在表里就落成顶层行）
- **界面语言**：目前仅中文 / English

```powershell
git clone https://github.com/rayfengleixing/tsflowy.git
cd tsflowy
npm install
```

### 开发模式（热更新）

```powershell
npm run tauri dev
```

首次运行会编译全部 Rust 依赖（约 5–10 分钟），之后增量编译只需数秒。

### 打包安装程序

```powershell
npm run tauri:build
```

产物为 NSIS 安装包（`target-dir` 由 `.cargo/config.toml` 指定为 `D:/Code/rust-target`）：

```
D:\Code\rust-target\release\bundle\nsis\TsFlowy_<版本号>_x64-setup.exe
```

例如当前版本：`TsFlowy_0.8.32_x64-setup.exe`。

> 打包前必须设置自动更新的签名私钥，否则构建会失败（`createUpdaterArtifacts` 已开启）：
>
> ```powershell
> $env:TAURI_SIGNING_PRIVATE_KEY = "<私钥文件路径或私钥内容>"
> npm run tauri:build
> ```
>
> 若私钥是空密码（`tauri signer generate --ci` 生成的即是），Windows 上把密码环境变量设成空串等于没设，构建会退回读控制台等待输入、在后台永久挂住。此时安装包照常产出，改用命令行参数显式传空密码单独补签：
>
> ```powershell
> node node_modules/@tauri-apps/cli/tauri.js signer sign `
>   D:/Code/rust-target/release/bundle/nsis/TsFlowy_<版本号>_x64-setup.exe `
>   -f D:/Code/.tauri/tsflowy.key --password=
> ```
>
> 构建完成后 bundle 目录会产出安装包及其 `.sig` 签名文件。再用下面的命令生成更新清单 `latest.json`：
>
> ```powershell
> npm run release:manifest -- --version 0.8.32
> ```
>
> 将安装包、`.sig`、`latest.json` 三者一并上传到 GitHub Release（tag 形如 `v0.8.32`），应用内「设置 → 软件更新」即可检测到新版本。私钥务必妥善保管、不要提交到仓库。

### 开发者提示

- SQL 迁移文件在 `migrations/`，按序号递增；已发布过的迁移禁止修改，只能新增。
- 数据库字段类型的判定（可分组、是否带选项、筛选比较符、粘贴文本解读、默认配置）集中在 `src/lib/field-kinds.ts` 注册表；新增一种字段类型只需在注册表补一条，编译会指出漏写的地方。
- Rust 与前端共用的字段类型知识写在 `contracts/field_type_contract.json`，两端各有一个测试读同一份文件核对；改了类型默认值要同步这份契约。
- 如本机磁盘空间紧张，可在 `.cargo/config.toml` 中把 `build.target-dir` 指到仓库外目录，或设置环境变量 `CARGO_TARGET_DIR`（该文件默认不入库）。

## 使用指南

1. 首次启动会自动创建一个工作区；点击侧边栏的「新建」按钮创建页面（文档或数据库）。
2. 编辑区输入 `/` 呼出斜杠菜单插入内容块；选中文本出现浮动工具栏；拖动块手柄可调整顺序。
3. `Ctrl+K` 打开命令面板跳转页面；`Ctrl+Shift+F` 全局搜索（含数据库内容），命中行点击直达。
4. 数据库页面顶部可切换 / 新建视图（表格、看板、日历），每个视图独立保存自己的筛选与排序配置。
5. 标签栏的导出菜单可将当前页导出为 Markdown / 长图 / PDF。
6. 删除的页面进入「回收站」，30 天内可恢复或彻底删除。
7. 设置页可切换主题与语言、导出 / 导入备份、迁移数据目录、批量导入 Markdown 文件夹。

## 数据存放位置

应用数据默认保存在**系统「文档」目录**下的 `TsFlowy` 文件夹（中文系统显示为「文档」，路径通过系统 API 解析，兼容 OneDrive 重定向）：

```
%USERPROFILE%\Documents\TsFlowy\
├── appflowy.db    # SQLite 数据库（页面、数据库表、设置等）
├── assets\        # 图片 / 附件等资源文件
└── logs\          # 运行日志：按天一个 tsflowy-YYYYMMDD.log（单日上限 4MB，最多留 7 天）
```

- 实现方式：启动时把系统约定的应用数据目录建成指向该位置的目录联接（Windows junction），程序内部路径不变、数据实际落在文档目录，便于自行备份与同步盘同步。
- 从 0.7.6 及更早版本升级：首次启动会自动把旧数据（`%APPDATA%\com.tsflowy.app`）迁移到新位置；若新位置已有同名数据则保留新位置数据，旧目录整体改名为备份留在原处。
- 备份与迁移：设置 → 数据 → 导出备份（zip 打包数据库与资源），在新机器用「导入备份」还原。
- 排障：`logs\` 里同时有后端运行日志和前端 console 级别的记录（WebView2 控制台普通用户打不开，所以前端日志也落在这儿）。反馈问题时用设置 → 数据库健康 → 导出诊断包，一次打包日志、库结构快检、内容统计和**已脱敏**的配置；AI 密钥走 Windows 凭据库，不在包内，凭据库不可用时的回退键也会在打包前被抹掉。
- 也可以把数据目录改到自定义位置（如同步盘），设置内提供目录迁移与恢复默认（恢复默认即回到「文档\TsFlowy」）。
