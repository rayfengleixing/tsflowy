# TsFlowy

本地优先的 Windows 桌面笔记与知识管理应用：文档编辑 + 数据库（表格 / 看板 / 日历）+ 全局搜索，数据全部保存在本机，无需账号、不依赖云服务。

基于 **Tauri 2（Rust）+ React 19 + TypeScript + TipTap + SQLite** 构建，安装包约 5.5 MB。想直接使用可从 [Releases](https://github.com/rayfengleixing/tsflowy/releases) 下载最新安装包；从源码构建与使用见下文。

## 功能特性

### 文档编辑

- 所见即所得富文本编辑器（TipTap / ProseMirror）：标题、段落、项目符号 / 编号 / 任务清单、引用、分割线、提示块（callout）、折叠块（toggle）、表格
- 代码块带语法高亮；数学公式（KaTeX）
- 输入 `/` 呼出斜杠菜单快速插入内容块；选中文本弹出浮动工具栏（加粗 / 斜体 / 下划线 / 删除线 / 高亮 / 文字颜色 / 链接）
- 块级拖拽手柄：拖动任意内容块调整顺序
- 图片：上传 / 粘贴 / 拖拽插入，可添加说明文字（caption），双击打开灯箱放大；支持图片组（多图网格展示）
- 附件：卡片式展示，点击用系统默认程序打开
- `@` 提及：链接到其他页面，悬停预览内容，点击跳转；页面底部显示反向链接（backlinks）
- 子页面、内嵌数据库视图（在文档中嵌入数据库表格预览，或插入跳转链接卡片）
- 大纲面板：实时收集 H1–H3，滚动时高亮当前章节，点击跳转
- 首行一级标题即页面标题：编辑区内修改会同步页面名，侧边栏重命名也会写回标题

### 数据库

- 多视图：同一张数据表可拥有多个视图（表格 / 看板 / 日历），每个视图独立保存筛选、排序、分组等显示配置，顶部标签栏随时切换
- 字段类型：文本、数字、日期、单选、多选、复选框、URL、电话、邮箱，以及自动维护的创建时间 / 最后编辑时间
- 表格视图：按字段分组并显示分组小计、底部合计行（每列可选汇总函数）、列统计、筛选与排序
- 看板视图：按单选字段分列，卡片展示字段可配置
- 日历视图：按日期字段铺排
- 行详情面板：逐行查看与编辑完整字段
- CSV 导入 / 导出

### 组织与检索

- 工作区（空间）切换、侧边栏页面树（拖拽排序、右键菜单、新建页面 / 数据库）
- 多标签页 + 面包屑导航
- 回收站：软删除、恢复、彻底删除，删除满 30 天自动清理
- 全局搜索（`Ctrl+Shift+F`）：覆盖页面标题、正文与数据库单元格，命中行可一键定位
- 命令面板（`Ctrl+K`）：快速跳转页面

### 导出、导入与备份

- 当前页面导出：Markdown / 长图 PNG / PDF
- 整个工作区备份导出与导入（打包数据库与附件资源，可整体迁移）
- 导入 Markdown 文件夹：按目录结构批量建页

### 外观与设置

- 浅色 / 深色 / 跟随系统主题；强调色与正文字体可选；界面支持中文 / English
- 数据目录可迁移（设置内指定自定义位置），备份一键导出

## 技术栈

| 层       | 技术                                         |
| -------- | -------------------------------------------- |
| 桌面框架 | Tauri 2（Windows / WebView2）                |
| 后端     | Rust，rusqlite（SQLite，WAL），命令式 IPC    |
| 前端     | React 19 + TypeScript + Vite                 |
| 编辑器   | TipTap 3（ProseMirror）                      |
| 样式     | Tailwind CSS 4 + Radix UI（shadcn 风格组件） |
| 状态管理 | zustand；SQL 层下沉 Rust，前端经命令调用     |
| 其他     | katex / lowlight / html-to-image             |
| 测试     | Vitest（前端）+ cargo test（后端）           |

## 从源码构建

```powershell
git clone https://github.com/rayfengleixing/tsflowy.git
cd tsflowy
npm install
```

### 开发模式（热更新）

```powershell
npm run tauri dev
```

首次运行会编译全部 Rust 依赖（约 5–10 分钟），之后增量编译只需数秒。

### 打包安装程序

```powershell
npm run tauri:build
```

产物为 NSIS 安装包：

```
src-tauri\target\release\bundle\nsis\TsFlowy_<版本号>_x64-setup.exe
```

例如当前版本：`TsFlowy_0.6.3_x64-setup.exe`。

### 开发者提示

- SQL 迁移文件在 `migrations/`，按序号递增；已发布过的迁移禁止修改，只能新增。
- 如本机磁盘空间紧张，可在 `.cargo/config.toml` 中把 `build.target-dir` 指到仓库外目录，或设置环境变量 `CARGO_TARGET_DIR`（该文件默认不入库）。

## 使用指南

1. 首次启动会自动创建一个工作区；点击侧边栏的「新建」按钮创建页面（文档或数据库）。
2. 编辑区输入 `/` 呼出斜杠菜单插入内容块；选中文本出现浮动工具栏；拖动块手柄可调整顺序。
3. `Ctrl+K` 打开命令面板跳转页面；`Ctrl+Shift+F` 全局搜索（含数据库内容），命中行点击直达。
4. 数据库页面顶部可切换 / 新建视图（表格、看板、日历），每个视图独立保存自己的筛选与排序配置。
5. 标签栏的导出菜单可将当前页导出为 Markdown / 长图 / PDF。
6. 删除的页面进入「回收站」，30 天内可恢复或彻底删除。
7. 设置页可切换主题与语言、导出 / 导入备份、迁移数据目录、批量导入 Markdown 文件夹。

## 数据存放位置

应用数据默认保存在：

```
%APPDATA%\com.tsflowy.app\
├── appflowy.db    # SQLite 数据库（页面、数据库表、设置等）
└── assets\        # 图片 / 附件等资源文件
```

- 备份与迁移：设置 → 数据 → 导出备份（zip 打包数据库与资源），在新机器用「导入备份」还原。
- 也可以把数据目录改到自定义位置（如同步盘），设置内提供目录迁移与恢复默认。
